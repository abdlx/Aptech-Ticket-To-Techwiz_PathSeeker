Executive Summary: From Confusion to Direction

PathSeeker is a modern full-stack Career Passport web application designed to guide students, graduates, and professionals from career uncertainty to confident, evidence-based career decisions.

The Challenge

  • Fragmented Information: Job market facts, salary statistics, and courses are scattered across opaque portals.
  • Black-Box Advice: Existing guidance engines give arbitrary job titles without explaining why a role matches.
  • Skill Blind Spots: Learners don't know the exact skills required to bridge the gap to their target roles.

The PathSeeker Solution

  • Durable Career Passport: Captures archetype, normalized trait signals, and verified profile skills.
  • Explainable Compatibility & Readiness: Separate scores for intrinsic fit vs. immediate skill preparation.
  • Interactive Simulator: What-if skill growth modeling without mutating underlying records.
  • Integrated Content: Direct access to 51 pages of PDF guides and curated Google Career Certificates videos.

Core Architectural Tenets

DETERMINISTIC

Auditable Intelligence

Scoring formulas are mathematical and version-locked on the server; zero hallucination.

ACCESSIBLE

Inclusive by Default

Theme switching, 85–130% font scaling, reduced motion, and complete keyboard navigation.

HUMAN-CENTERED

Navi Guidance

Contextual assistant supporting voice and text mode for intuitive navigation and exploration.

PathSeekerSYSTEM ARCHITECTURE & STACK
05
Full-Stack Design

Layered MERN Architecture & Request Flow

[Client Layer] React 18 + Vite (SPA) ── TanStack Query v5 (Server Cache) ── Zustand (UI/Preferences)
                        │ (HTTP JSON API + HttpOnly Cookie Auth)
[API Gateway] Express.js ── Helmet ── CORS Allowlist ── Rate Limiters ── Context / Logging
                        │ (Controller Layer ── Input Validation ── Session Middleware)
[Domain Services] AuthService · PassportService · RecommendationEngine · CatalogService · Moderation
                        │ (Mongoose ODM Models & Schemas)
[Data & Storage] MongoDB 7+ (Indexed Collections) + Local Upload Storage + Vapi Voice Webhooks

Frontend (Vite + React)

Modular component system, React Router 6, TanStack Query for data fetching, React Hook Form with Zod validation, responsive CSS tokens.

Backend (Node + Express)

RESTful API architecture, layered controller-service pattern, bcrypt password hashing, cryptographic token generation, comprehensive error handling.

Database (MongoDB)

27 Mongoose models, compound text & unique indexes, time-to-live expiration for sessions/tokens, append-only recommendation snapshots.

End-to-End Request Lifecycle

1User Action: Learner selects an answer choice in the career assessment or adjusts a skill slider.
2API Dispatch: TanStack Query mutation fires with JSON payload and active session credentials.
3Protection & Auth: Express middleware verifies CSRF/CORS, rate limits, and decodes opaque session cookie.
4Service Execution: Controller delegates to domain service which performs deterministic calculation and updates MongoDB.
5State Reconciliation: Fresh data payload returns to browser, triggering query cache invalidation and toast alert.

Deterministic Scoring

Passport Calculation & Recommendation Engine

1. Career Passport Scoring Formulas

TraitScore(T) = (SelectedOptionCount(T) / MaxPossibleOptions(T)) * 100
DomainScore(D) = (AccumulatedDomainWeight(D) / MaxPossibleDomainWeight(D)) * 100
CompletionScore = (PresentProfileSignals / 7) * 100

2. Career Match & Readiness Formulas

Compatibility% = (TraitAlignment * 0.55) + (InterestAffinity * 0.25) + (SkillOverlap * 0.20)
Readiness% = WeightedAverage( min(1.0, UserSkillLevel(s) / RequiredSkillLevel(s)) )
ConfidenceScore = 55 + min(40, TotalEvidenceDataPoints * 4)

Compatibility (Fit)

Reflects how naturally the user's personality traits and intrinsic interests match the daily realities of the career.

Readiness (Preparedness)

Evaluates technical mastery across critical, important, and nice-to-have skill prerequisites (0–10 scale).

Skill-Gap Priority

Calculated as: Gap * ImportanceWeight * 20, automatically sorting which competencies the learner must prioritize.

Stateless Simulation Invariant: Simulator calculations occur on-the-fly and return persisted: false, guaranteeing that experimenting with skills never corrupts verified learner records.

Why PathSeeker Stands Out: Core Technical Differentiators

PathSeeker rejects marketing superficiality in favor of verifiable software engineering rigor. Below are the 8 architectural and functional differentiators that set PathSeeker apart from standard student projects.

1. Explainable Dual-Metric Intelligence

SCORING ENGINE

Traditional tools conflate interest with qualification. PathSeeker decouples Compatibility % (intrinsic behavioral & psychological fit) from Readiness % (immediate prerequisite mastery), explaining exactly why a role is recommended.

Formula: (Trait*0.55) + (Interest*0.25) + (Skill*0.20)

2. Immutable Assessment Snapshots

DATA INTEGRITY

Assessment attempts freeze question text, option choices, and trait weights at the exact time of submission. Admins can update future question banks without corrupting or invalidating historical student records.

Model: QuizAttemptSchema.attemptSnapshot (ReadOnly)

3. Stateless Interactive Skill Simulator

SIMULATION

Enables learners to test "What-if" skill growth scenarios in real time. Calculations execute dynamically on the client and server returning persisted: false, preventing accidental data pollution.

Endpoint: POST /api/careers/:id/simulate (Ephemeral)

4. Navi Conversational Voice AI Mode

VOICE AGENT

Full hands-free conversational agent supporting real-time voice speech synthesis, intent detection, animated mood visualizers (Listening, Thinking, Speaking), and automatic application deep-linking.

Stack: Vapi WebSockets + Web Speech API fallback

5. BLS-Backed Occupational Rigor

AUTHENTIC DATA

Zero generic placeholder careers. All 15 occupational profiles incorporate authentic U.S. Bureau of Labor Statistics (2024–2034) median wage percentiles, 10-year growth demand, and education prerequisites.

Source: U.S. Bureau of Labor Statistics (2024–2034)

6. WCAG 2.1 AA/AAA Accessibility

INCLUSIVITY

Engineered for all learners: theme switching (Sage Light / Forest Dark), fluid font scaling (85%–130%), prefers-reduced-motion compliance, visible focus rings, and ARIA dialog modal traps.

Standard: WCAG 2.1 AA/AAA Compliant Tokens

7. Comprehensive 6-Module Admin Center

GOVERNANCE

Production-ready governance: User role management, career catalog editor, immutable quiz version publishing, success story moderation workflow, feedback triage queue, and system audit logs.

Scope: 6 Dedicated Workspaces with Role Guards

8. 47 Passing Automated Tests & Zero Lints

RELIABILITY

Verified through 36 backend integration and unit test suites plus 11 frontend test suites, 0 ESLint errors, strict Zod schema validation, and complete reproducibility across all environments.

Evidence: 36 Backend + 11 Frontend Suites Passed
