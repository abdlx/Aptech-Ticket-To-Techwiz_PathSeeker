Engineering Summary

Transforming Career Uncertainty into Actionable Evidence

PathSeeker is a functional, full-stack Career Passport web platform engineered to bridge the disconnect between self-assessment and occupational realities for students, graduates, and professionals.

Architectural Problem Space

  • Opaque Recommendations: Legacy platforms provide black-box job titles without mathematical justifications.
  • Fragmented Competency Taxonomies: Labor statistics, skill prerequisites, and workbooks are siloed across disconnected websites.
  • Missing Preparation Visibility: Learners cannot see their quantitative readiness delta or test what-if learning scenarios.
  • Content Inflexibility: Educational institutions cannot publish customized curriculum resources without code redeployment.

Delivered Engineering Solution

  • Durable Career Passport: Persists versioned psychometric traits, verified skills, and occupational goals.
  • Deterministic Scoring Engine: Computes explainable Compatibility, Readiness, and Confidence based on U.S. BLS 2024–2034 data.
  • Stateless Growth Simulator: Allows testing skill upgrades without altering stored profiles or historical assessments.
  • Modular Admin & Resource Hub: Empowers content editors to manage careers, quizzes, original PDFs, and video media with full auditability.

Primary Learner Journey Architecture

1Register & Verify Identity: Account creation with email validation, bcrypt password hashing, 6-digit cryptographic OTP generation, and HttpOnly session issuance.

5Explore, Simulate & Upskill: Analyze career details, simulate skill growth, save bookmarks with private notes, download original PDF roadmaps, and track notifications.

Node.js 20.x LTS or higher, npm 10.x+, MongoDB 7.0+ community or Atlas instance with write access.

End-to-End Request Execution Lifecycle

1Client Navigation & Query Dispatch: React Router lazy-loads destination view; TanStack Query dispatches HTTP request via apiClient.js with credentials and cancellation token.
2Gateway Interception & Middleware: Express passes request through helmet(), CORS allowlist check, express.json({ limit: '1mb' }), cookieParser(), and request correlation ID generator.
3Authentication & RBAC Verification: requireAuth extracts session cookie, computes SHA-256 hash, queries Session collection, reloads User, and requireRole enforces role permissions.
4Controller & Service Logic: Controller validates input DTO against Zod schema; domain service executes business invariants, calculates deterministic metrics, and coordinates Mongoose models.
5MongoDB Persistence & Population: Mongoose executes indexed queries, applies schema pre-save hooks, populates foreign relationships, and persists immutable snapshots.
6Enveloped Response & Cache Reconcile: Server returns standard JSON envelope { data: ... }; TanStack Query updates memory cache and triggers reactive UI re-renders.

Production Infrastructure Topology

Frontend Hosting

Vite-compiled static single-page application served via CDN (Vercel, Netlify, or Nginx) over HTTPS.

Backend API Service

Containerized Node.js Express process hosted on cloud platform (Render, Railway, or VPS) with environment secrets.

Database & External

MongoDB Atlas 7+ replica set with automated backups; Resend API for email delivery; Vapi WebSocket for voice agent.

Client Resilience & Fault Tolerance

Request Timeout (15s)

apiClient.js attaches AbortController with a 15-second timeout, distinguishing network aborts from user navigation.

Bounded Retries

Failed GET queries retry up to 2 times with exponential backoff, strictly ignoring 400, 401, 403, and 404 client errors.

Standardized Error Toast

Extracts safe user message and correlation ID from backend error payloads, displaying actionable Sonner notifications.

Identity & Access Control

End-to-End Authentication & Session Lifecycle

1Registration & Password Hashing: User submits name, email, password, and stage. Backend normalizes email to lowercase, verifies uniqueness, hashes password with Bcrypt (cost 12), and creates a pending_verification user document.
2Cryptographic OTP Generation & Delivery: auth.service.js generates a 6-digit numeric OTP via crypto.randomInt(100000, 999999), computes SHA-256 hash, stores in VerificationToken (+15 min TTL), and dispatches email via Resend (or console in dev).
3OTP Verification & Account Activation: User enters OTP; server verifies token hash, confirms attempts < 5, marks emailVerified: true, updates user status to active, and burns the token.
4Login & Secure Session Creation: On valid credential check, server generates a high-entropy 32-byte session token via crypto.randomBytes(32).toString('hex'), stores SHA-256 hash in Session (+7 day TTL), and writes raw token to an HttpOnly cookie.
5Authenticated Request & RBAC Resolution: requireAuth middleware extracts session cookie, hashes value, looks up active non-revoked session, loads User, and requireRole enforces role permissions (e.g. staff, admin).
6Session Termination & Multi-Session Revocation: Logout revokes the calling session token. Password reset generates a single-use SHA-256 reset token, updates password hash, and invalidates all active sessions for that user.

Deterministic Algorithms

Scoring Mathematical Formulas & Snapshot Rules

PathSeeker employs 100% deterministic, explainable mathematics (Algorithm: passport-v1 and recommendation-v1) without non-reproducible black-box heuristics.

Passport-v1 Scoring Formulas

TraitScore(t) = round( (Count(t) / MaxTraitCount) * 100 )
DomainScore(d) = round( (TotalWeight(d) / MaxDomainWeight) * 100 )
CompletionPercent = round( (EvidenceSignals / 7) * 100 )

7 Evidence Signals: Headline, Education entries, Skills list, Interests, Primary goal, Completed onboarding, Fully answered assessment.

Recommendation-v1 Formulas

TraitAlignment = mean( TraitScore(career.traits) )
Compatibility = round( (TraitAlign * 0.55) + (Interests * 0.25) + (SkillAffinity * 0.20) )
Readiness = round( ( ∑ min(1, userSkill / reqLevel) * weight ) / ∑ weight * 100 )
Confidence = round( 55 + min(40, evidenceCount * 4) )

Weights: Nice-to-have = 1, Important = 2, Critical = 3.

Skill Gap Analysis & Simulator Safety

Skill Gap Mathematical Delta

For each career prerequisite: Difference = max(0, requiredLevel - currentLevel).
ReadinessImpact = clamp( (Difference / requiredLevel) * weight * 20 ).
Gaps are sorted by highest ReadinessImpact first to prioritize immediate learning needs.
